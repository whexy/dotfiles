# firefox-windows-profile

Windows Firefox configuration generated by Nix from the same source of truth
as the NixOS/Darwin Home Manager module
(`nix/modules/home/browser/firefox/shared.nix`).

## Contents

| File                        | Destination                                                          |
| --------------------------- | -------------------------------------------------------------------- |
| `user.js`                   | `%APPDATA%\Mozilla\Firefox\Profiles\<profile>\user.js`               |
| `chrome/userChrome.css`     | `%APPDATA%\Mozilla\Firefox\Profiles\<profile>\chrome\userChrome.css` |
| `policies.json`             | `C:\Program Files\Mozilla Firefox\distribution\policies.json`        |
| `Install-FirefoxConfig.ps1` | installer (self-elevates for `policies.json`)                        |

## Usage

From the WSL host:

```sh
just firefox-windows
```

This builds the bundle, copies it to `C:\Windows\Temp\firefox-windows-profile`,
and runs the PowerShell installer (a UAC prompt will appear). Restart Firefox
afterwards.

Or manually: `nix build .#firefox-windows-profile`, copy `result/` to Windows,
and run `Install-FirefoxConfig.ps1` in PowerShell.

## Notes / differences from the NixOS setup

- **Search engine**: Home Manager writes `search.json.mozlz4` into the
  profile, but that file embeds a hash of the local profile path, so it cannot
  be reused across machines. The bundle instead uses the `SearchEngines`
  enterprise policy (Firefox 139+) to add "Unduck" and set it as default. The
  policy has no private-browsing default, so set that once in Firefox settings
  if desired.
- **policies.json** goes in the installation directory (requires admin) — on
  NixOS it is baked into the wrapped package instead.
- The macOS-only prefs (fullscreen behavior, titlebar) and HiDPI compensation
  are intentionally excluded.
